# Raft Design

The Raft Design System and raft-ui, its React implementation. The system's rules, foundations and component guides live in [`design/`](./design/README.md); raft-ui brings expressive visuals and playful interactions, shaped by Raft and made for whatever you build next.

- **Plain HTML:** shared theme variables in `raft-ui/foundation.css`, with no React or Tailwind build.
- **React:** composable components built with Base UI and Tailwind CSS v4.

See [package usage](./packages/ui/README.md) and the [technical overview](./packages/ui/skills/raft-ui-guide/rules/technical-overview.md).

## Preview

- Repository: https://github.com/botiverse/raft-design
