# 模式

组件怎么拼成页面。这一页只写每个产品都用得上的搭法；某个产品自己的信息结构（有哪些一级入口、首页放什么、频道里有哪几个视图）写在它自己那一页，现在是《Raft Chat》。这里的结构和行为都照着产品代码里已经定下的规则；做新功能时，先找最接近的一节照着搭。

## 页面骨架

### 手机
| 页面 | 顶 | 中 | 底 |
| --- | --- | --- | --- |
| 一级页：Tab 栏上的入口 | 黄色外框：状态栏，下面是大标题写页名（可以带一行副标题，或一行“谁在干活”）。要放工作区胶囊或图标按钮的页面，大标题上面多一行 56 高的导航；不放的页面不留这一行，大标题直接接在状态栏下面。和线上一样的版本不写大标题（见 NavBar） | 列表直接坐在纸上，或者分组卡片 | Tab 栏 |
| 二级页：push 进去的 | 顶栏：返回、标题，右边最多一两个图标按钮。白底、黄底两版待定（见 NavBar） | 内容 | 能发消息的页面是 composer；其他页什么都没有——Tab 栏被盖住了 |
| 弹出来的 | — | Menu（长按，对一样东西做事）、Select 的列表（选一个值）、Dialog（确认）、底部列表（选一个去处：工作区、Working now）、底部弹层（一小段说明） | — |

### 桌面
- 从左到右：Rail（黄；只放图标 56，或图标加字 68）→ 侧栏（240，奶油，可拖 180–320）→ 主区（白：面板头、内容）→ 需要时右边停一栏（380–400）。
- 网页版在这一切上面多一条外框顶栏：48 高、黄（暗色为中性外框色），下沿 `line-seam`；左边工作区、正中搜索框、右边“谁在干活”和铃铛，控件都是 36 高的外框项，离顶栏上下各 6、左右各 8（和 Rail 的间距一样），工作区按钮和 Rail 的按钮对齐。有顶栏时 Rail 没有头，第一个入口离顶栏的分区线 8。桌面 App 的标题栏同样是这一条 48 高的外框。
- Rail 头、侧栏头、面板头都是 56 高，下沿的分区线对齐；Rail 头是 56×56 的正方形。区域之间都是 `line-seam`。
- **两个区域之间只有一条线**，永远不并排两条（并排的两条 1px 读起来就是一条 2px 的粗线）：先画的一方负责——Rail 和侧栏画自己的右沿，挨着它们的会话、Activity 不再画左沿；附着在会话旁边的右边一栏画自己的左沿。区域边界用 `line-seam`，内容内部用发丝线 `line`。
- **一列内容只有一条边**：面板头的第一个元素、分页的第一张贴纸、消息的头像列、输入框的外框都在 20（手机 16，消息列和输入框仍对齐 20）；每一行最右边的图标，图标框止于同一条边（怎么对齐见《基础》的“对齐”）。
- 侧栏跟着 Rail 走：Rail 上选中哪个入口，侧栏就列它的内容；没有侧栏的入口，内容直接接在 Rail 右边。
- 右边一栏放线程、任务、文件、资料这类“和主区一起看”的东西：一次只停一栏，打开新的就换掉旧的；屏宽不到 1024、或者并排以后主区不到 320 时，盖住主区（见“宽和窄”）。

### 一屏里的层次，从外往里
黄（外框）→ 奶油（侧栏）→ 白（内容）→ 白卡片（发丝线）→ 浮层（`popover` 底、分区线边、软阴影）。暗色里换成一层比一层亮的深色。

## 导航
- **一级入口**：手机是底部的 Tab 栏，最多 5 个，只出现在一级页；桌面是 Rail，底部放通知、帮助、设置。每个产品放哪几个，见它自己那一页。
- **你在哪**：纸面上是黄贴纸（侧栏行、分段控件、分页标签；Tab 栏只包图标）；Rail 的选中在亮色的黄外框里是白贴纸，在暗色里是黄贴纸；你所在的地方（比如一个频道）标题旁有一块黄色位置块。
- **去哪看看**：正文里的引用 chip（地方浅粉、某条内容浅青）和蓝色链接；跳过去的那一项铺一层浅青。
- **回去**：push 进去的页面左上角是返回，返回走浏览历史；直接打开的链接一层层退回到一级页。要换 Tab，先回到一级页；点任何一个 Tab 都回到它的一级页，不记子页。
- **关掉**：弹窗右上角有 ×；铺满屏幕的只有返回；桌面上停在右边的一栏有 ×。
- **工作区**：手机在首页顶上的胶囊，桌面在 Rail 顶上的方块；点开是同一份列表——手机从底部升起，桌面贴着方块弹出。别的工作区有未读时，胶囊和方块上挂提醒点。
- **一个地方的几种内容**（对话、任务、文件这类）：一行分页（贴纸或下划线）、顶栏里的分段，或者把其中一种放进右边一栏和主区同时看。一个产品里只选一种，几种样子见 Tabs 和 ScreenChannelViews。

## agent
| 要表达 | 用 |
| --- | --- |
| 这是一个 agent | 像素头像，名字后面加 `agent` 标签；运行时签写它跑在什么上（Claude Code、Codex） |
| 它现在怎么样 | 头像上的状态灯；需要写成字时用状态签 |
| 它正在干活 | 写在它出现的地方：头像上一盏静止的黄灯；它那一行的第二行换成它正在做的事；对话里它的状态行；页面顶上一行写有几个在干活（见下面） |
| 它做完了 | 一条消息加证据条（CI、commit、快照）；任务的状态跟着变 |
| 它认领、交接 | 事件行：Bugen claimed #25；Wug → Martin · review #25 |
| 它要人授权 | 对话里的 ActionCard（只是摘要，Edit First 打开平常那个能改的对话框），同时进动态 |
| 它出错了 | 橙灯；它那一行和状态行写原因；影响到整个工作区的（电脑离线）进通知中心 |
| 它做过什么 | Timeline 的活动日志，用机器字 |
| 它不在这个工作区的电脑上 | 青灯，运行时签写它在哪 |

- agent 和人平等：同一种消息、同一种方头像、同一种列表行；详情页里列 agent 和人，都用分组卡片里的 ListRow。
- agent 的动作写成事件行，不写成消息；不做“正在输入”，灯不闪。
- 不用“AI”“bot”这类字眼，也不用闪光、星星这类图标；agent 靠像素脸和名字被认出来。

### 正在干活，放在哪
人想知道三件事：有没有谁在干活、是谁、在干什么。前两件扫一眼就够，第三件到对应的地方去看。所以：
- **一行摘要**放在页面标题下面（手机首页）或侧栏头上（桌面）：一叠头像加“2 agents working”，点开是 Working now 列表（手机从底部升起，桌面贴着那叠头像弹出）。没有人在干活时这一行收起来，不写“0”。
- **每个 agent 的行**在它干活时，第二行换成它正在做的事（实时、墨色），时间换成干了多久；做完了换回最后一条消息。
- **所在的地方**：频道这类页面的顶栏副标题写谁在这里干活；对话的最后是它的状态行。
- 不做贴在 Tab 栏上面或侧栏底部的实时条：它占着屏幕上最好的位置，一直在变，却往往和你正在看的东西无关。
- 变化只用一个短动画：有 agent 开始或停下时，那叠头像里的脸滑开、淡入淡出（`--rf-ease-slide`，180–220ms）；字直接换成新的，不做数字滚动，不闪。

## 任务
- 五种状态，颜色固定：Todo、In Progress、In Review、Done、Closed。“需要你”不是一种状态：它是一个动作（ActionCard 的按钮），加一个提醒点。
- **任务列表**（不管是一个产品里的任务页，还是某个地方的任务分页）：上面一条筛选，最右边是 Board / List；看板一列一种状态，拖卡片就是改状态；列表按状态分组，Done 和 Closed 默认收起。手机默认列表。
- **任务详情**是居中的弹窗（最宽 760，手机上铺满）：一行 Status / Assignee / Created by，History 折叠在下面；有对话的产品，再下面是这个任务的线程。
- **改状态**：卡上的状态签、详情里的属性、看板上拖动。
- **筛选**：任务所属的地方、Assignee、Creator；“我建的”“交给我的”作为筛选列表里的两行，不另做按钮；“没人认领”排第一、不带头像。各产品的具体筛选项见它自己那一页。

## 对话
- 一条时间线：消息、事件行、日期，最新的贴底。同一个人同一天的连续消息合并；带任务或线程的消息不合并。合并的那几条，悬停时在左边空白处显示时间，不加动画。
- 消息里能有：@（别人是墨色下划线，你是小黄贴纸）、引用 chip、蓝色链接、行内代码、代码块、引用、附件、行动卡、证据条。
- 消息下面：一行任务标记和回应；再下面是线程回复（最多 3 条预览）。
- 动作：桌面悬停时，这一条的上沿骑着一个小工具条（Reply in Thread、Add Reaction、Save）；其他动作在菜单里——桌面右键、手机长按，是同一个菜单，第一行是快捷回应，它和下面的动作之间一条分隔线。
- 线程：手机上 push 一页；桌面上在右边一栏打开，放不下时盖住对话。线程只有对话和 composer。
- 搜索：结果按种类分组，命中的词是小黄贴纸；选中一条在右边打开，跳到的那一条铺一层浅青。

## 表单和设置
- 字段：标签在上，帮助在下；可选的标 (optional)。选哪个控件，见《组件》的“让人选一样东西”。
- **立即生效**（设置页）：开关、单选、下拉，改了就存，不放保存按钮。
- **要保存的**（对话框、抽屉里的表单）：底部 Cancel / Save，Save 是这一屏的粉色，按钮都是 44。是 / 否用复选框，不用开关。
- **一次填完的大表单**（注册 / 编辑一个应用、一个 agent 的配置）：居中的宽弹窗（Dialog 宽版，896，固定高度），不跳到设置页。头 56 是它的贴纸、标题和 ×（标题就是打开它的那句话，Register App；改的时候写 Edit 加它的名字），头里不放提交；左边一列分段列表（侧栏行，正在读的那段是黄贴纸，跟着滚动走），右边分段（FormSection：小标题、状态签、一句说明、段间发丝线）；底栏 Cancel 在前、粉色在后。点外面不关闭，× / Esc / Cancel 关闭。手机上几乎铺满，没有分段列表。
- 新建时只出现保存前就能填的段；分享、发布、密钥、删除这类针对已存在对象的段，保存以后才出现。段里的操作是普通的一行（左边说明、右边按钮），不是卡片里再套卡片。
- **校验**：离开输入框或提交时检查；框变深红，帮助文字改写成怎么改；不弹 toast。
- **危险区**：放在页面最后；会打断但能恢复的用橙（停止、离开、重置），收不回的用红（删除）；删 agent、删工作区这类大东西，要输入名字确认。
- **别先摆一个用不了的表单**：缺前提时先说清楚、给出路（比如先连一台电脑，再建 agent）。

## 反馈
- 用哪一种，见《组件》的“告诉人一件事”。
- 能撤销就不用确认：先做，再给一条带 Undo 的 toast。删除这类收不回的，由对话框把关，菜单里不另上色。
- 空、加载、出错分清楚：空用 EmptyState（只有一种样子：灰色图标、一句话、最多一个按钮），加载用骨架，出错按范围，范围越大放得越外：输入框里的报错、对话框和表单里的提示条、面板头下面的通栏（一个面板里的东西：agent 起不来、设置没存上）、整个工作区的进通知中心（见 Banner）。
- 加载时不闪、不跳：骨架和最后的内容一样大，不先出一块再换成另一块。
- 读不出来不是空：加载失败按上面的范围显示出错（说清楚、能重试），不显示空状态——空状态说“这里没有东西”，是一句结论。
- 进度放在东西里面：一条独立的细轨道，不贴在卡片、输入框这类圆角容器的边上（见《基础》的线）。
- 出错写人话：现在怎么了、为什么、下一步做什么。出了问题用橙，不用红。

## 暗色模式
- **变的**：底（外框和侧栏 `#0d0d0b` → 内容 `#1b1b19` → 容器 `#242422` → 浮层 `#292927` → 填充 `#32322f`）、墨、线、浅底、任务状态的像素颜色。外框不用黄，但 Rail 的选中项是黄贴纸（那是“你在这”，不是外框）。
- **不变的**：贴纸不反色——头像、粉色按钮、黄色选中、开关、位置块、徽标、工作区（墨底黄字）、表情回应都一样；边缘是墨色像素的贴纸，外面加一圈 `sticker-edge` 模切边。模切边要加在每一张贴纸上：头像；黄色选中（侧栏行、Rail 项、分页、分段、切换组、手机 Tab 栏）；粉、橙、红按钮（禁用时不再是贴纸，不加）；开关；计数和 @ 徽标；消息和 Markdown 里叫到你的标记；回复数。模切边在贴纸盒子外面，所以贴纸盒子对齐网格，看上去的边缘也就对齐——暗色里头像和分页贴纸不会差出 3px。也因为它在盒子外面，装贴纸的地方不能裁切：截断（省略号）只用在文字上，同一行里的签、徽标、头像放在被截断的那段文字外面。
- 每个新组件都在两种主题下各看一遍。

## 品牌元素用多少
| 场景 | 可以用 |
| --- | --- |
| 工作页：列表、对话、任务、设置、空状态 | 黄色外框、工作区胶囊、最多一个粉色主操作、墨线控件、头像和状态灯这些小块颜色 |
| 一个 agent 或一个人的主页 | 再加大号像素贴纸、硬阴影、慢慢漂浮 |
| 引导页、登录、App 内的营销页 | 再加整屏黄、半调网点、40px 标题、全大写的步骤签、logo |

越往下越接近官网。下面两行的东西不出现在工作页里，空状态也一样。

## 宽和窄
| 宽度 | 布局 |
| --- | --- |
| < 768 | 手机：一级页加 Tab 栏，其他页 push 进去；右边一栏的东西（线程、任务、资料）都变成 push 进去的一页；任务详情铺满 |
| 768–1023 | Rail + 侧栏 + 主区；右边一栏盖住主区；任务详情是居中的弹窗 |
| ≥ 1024 | 右边一栏并排以后主区还有至少 320，就停在主区旁边（380）；否则盖住主区。各产品可以再加条件（Raft Chat 的线程见那一页） |
| 桌面窗口矮于 600 | 最外层加 `rf-short`：头从 56 收到 48，Rail 跟着收到 48（左上角还是正方形），Rail 项从 40 收到 36；图标加字的 Rail 藏起字 |

- 手机按 390 宽来设计，窄到 320 也要放得下：长名字截断；按钮换行，不缩字号；分段控件不超过 4 段，放不下就只留图标；分页标签横向滚动（见 Tabs：滚轮也能横着滚，藏着标签的一侧渐隐，选中的那张总在视野里）。
- 触屏上没有悬停工具条；手机竖着拿时，composer 的回车是换行。
