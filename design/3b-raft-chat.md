# Raft Chat

Raft Chat 是 Raft 的第一个产品：频道、私信、agent 和任务在同一条对话里。这一页只写 Raft Chat 自己的信息结构——有哪些入口、每一页放什么、东西放在哪；颜色、组件和通用的页面搭法见前面几页。这里的规则都来自 Raft Chat 的产品代码，别的产品不一定照搬。

## 一级入口
| | 入口 |
| --- | --- |
| 手机 Tab 栏 | Home、Tasks、Members、Settings。访客没有 Members |
| 手机首页的头三行 | Search、Activity（带新动态数）、Saved（灰色的数字）：三行入口，之间不画线 |
| 桌面 Rail | 工作区；Search、Chat、Activity、Tasks、Members、Computers；底部 Notifications、Help、Settings。访客没有 Members 和 Computers |
| 只在设置里 | Computers（手机）、Account、退出登录 |

- 提醒点：Rail 上 Chat 有未读、Activity 有新动态、Computers 有电脑要处理、Settings 有反馈回复时挂粉色像素；手机 Tab 栏上只有 Settings 挂（反馈有了新回复），其他新东西在页面里显示——首页的 Activity 行带数字。
- 铃铛是通知中心：整个工作区的事（电脑离线、额度快满、有更新）。手机在首页右上，桌面在 Rail 底部。Activity 是别处发生、要你看到的事（@你、回复、交给你的任务）。

## 侧栏（桌面）
- Chat 列频道、Agents、私信三组；Members 列成员；Settings 列设置的分组，默认打开 Account。
- Tasks 没有侧栏，看板直接接在 Rail 右边。
- Search 和 Activity 选中一条结果后，侧栏的位置换成结果列表（768–1023 宽 320，≥1024 宽 560，开了右边一栏时 320），结果在右边一栏打开。
- 侧栏头写入口的名字；Chat 的侧栏头右边是那叠正在干活的头像和人数。

## 首页（手机）
1. 外框：工作区胶囊（点开从底部升起工作区列表）和铃铛；下面是大标题 Home，再下面一行是正在干活的 agent（一叠头像加“2 agents working”，点开 Working now）。和线上一样的版本没有大标题，头像缩成胶囊右边的一小叠加人数。
2. 列表：Search、Activity、Saved 三行入口，之间不画线；然后是 Channels、Agents、Direct messages 三组 ListRow，组里的行之间是发丝线。
3. agent 行：在干活时，第二行写它正在做的事（实时，墨色），时间写干了多久；不在干活时写最后一条消息。
4. 这一屏没有粉色按钮：新建在各组标题的右边。

## 频道
- **顶栏**（二级页）：返回、黄色位置块、频道名；副标题先写正在这里干活的（一叠头像加“2 agents working”），再写成员数。⋯ 打开频道详情（桌面是右侧抽屉，手机是一整页）。
- **对话、任务、文件**：四种呈现，见 ScreenChannelViews，一个版本里只用一种：

| 版本 | 样子 | 适合 |
| --- | --- | --- |
| A 贴纸分页（默认） | 面板头下面一行分页，选中是黄贴纸；三种内容轮流占满主区 | 三种内容一样重要 |
| B 下划线分页 | 同一行，只写字，选中是墨色字加 2px 墨线（产品现在的样子） | 想让分页的颜色更少 |
| C 顶栏里的分段 | 分段控件坐在面板头右边，省掉一行（主区多出 44 高）；频道名长、或者手机上放不下时退回 A | 屏幕矮，想给对话多留一行 |
| D 任务在右边一栏 | 对话一直在主区；面板头右边的 Tasks、Files 是开关，打开的那一个停在右边（380）和对话同时看，一次一个；放不下时盖住对话（规则见下面“宽和窄”） | 一边聊一边看任务 |

- **D 在手机和窄屏上**：手机上没有右边一栏，频道顶栏右边是任务按钮和 ⋯（文件在 ⋯ 打开的频道详情里，顶栏最多两个图标按钮）；点任务 push 进这个频道的任务页（标题 Tasks，副标题写频道名和几个没做完），返回回到对话。桌面放不下时，右边一栏盖住对话，× 关掉回到对话。
- **任务在对话里**：发出来的那条消息就是任务，底部挂一枚任务标记（状态像素、`#25`、认领的人）；点它打开任务，不在这里改状态。新建：composer 的 As Task（⌘ / Ctrl + Shift + Enter）、消息菜单里的 Convert to Task、频道任务视图右上墨线的 Create Task。全局任务页没有新建：任务总要挂在一个频道上。消息菜单里可以直接标完成。

## 线程
- 手机上 push 一页，标题写 Thread，副标题写在哪个频道。
- 桌面上，主区至少 680 宽、而且是横屏或屏宽 ≥1280 时，线程停在右边（默认 400，最窄 360，最宽到屏宽的 60%），对话至少留 320；其他时候线程盖住对话。
- 线程和任务、文件、资料共用右边那一栏，一次一个。线程只有对话和 composer，没有分页、没有 Join。任务的线程在任务详情里。

## 正在干活的 agent 放在哪
| 地方 | 写什么 |
| --- | --- |
| 手机首页，大标题下面 | 一叠头像加“2 agents working”，点开 Working now |
| 手机首页，和线上一样的版本 | 胶囊右边一小叠头像加人数 |
| 桌面 Chat 侧栏头 | 一叠头像加人数，点开同一份 Working now |
| agent 行 | 手机：第二行写它在做什么；桌面侧栏：右边的运行时换成它在做什么 |
| 频道顶栏 | 副标题：一叠头像加“2 agents working · 5 members” |
| 对话里 | 时间线最后它的状态行，带一盏静止的黄灯 |

Working now 列表：每个正在干活的 agent 一行，写在做什么（带任务号）、干了多久；点一行跳到它所在的频道或任务。

## 任务页
- 手机一级页：大标题 Tasks，副标题写有几个任务；下面一条筛选（Channel、Assignee、Creator），最右边 Board / List，默认 List，选过的会记住。Created by me、Assigned to me 是筛选列表里的两行；Unassigned 排第一。
- 桌面：没有侧栏，看板直接接在 Rail 右边。
- 频道里的任务视图和任务页是同一个面板，只是少了 Channel 这个筛选。

## 宽和窄（只属于 Raft Chat 的）
| 情况 | 布局 |
| --- | --- |
| < 768 | 不自动打开第一个频道：先看到首页 |
| Search、Activity 的结果列表 | 768–1023 宽 320，≥1024 宽 560，开了右边一栏时 320 |
| 线程并排 | 主区 ≥680，而且横屏或屏宽 ≥1280：线程 400（360 到屏宽的 60%），对话至少留 320；否则盖住对话 |
| 资料、任务、文件的右边一栏 | 通用规则：屏宽 ≥1024，而且并排以后对话还有至少 320，就停在旁边（380）；否则盖住对话 |
