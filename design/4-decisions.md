# 取舍

这套系统的结构和行为跟着产品代码走：导航、页面怎么搭、任务和消息怎么呈现、菜单和空状态，都照产品里已经定下的规则。和产品不一样的只有下面这些取舍，每一条都写了理由。标 ⚑ 的几条推翻了产品负责人在代码里写明的决定，要改回产品的样子，只动这一处。这套系统是怎么一轮轮改到现在的，见 [`archived/rationale-history.md`](archived/rationale-history.md)。

## 和产品代码有意不同的地方
| 哪里 | 产品代码 | 这里 | 为什么 |
| --- | --- | --- | --- |
| ⚑ 粉色 | `#FE7DA8`（五个基础色之一） | `#FF99C3` | 配黑字从 7.8:1 提到 9.5:1，和紫、橙、青站到同一档；要和代码统一，只改这一个值 |
| ⚑ 大写 | 分组标题、对话框标题、徽标用全大写 | 句首大写；能点的字照样用 Title Case | 规则 7：不用全大写 |
| ⚑ 手机 Tab 栏 | 选中的那一格整格变黄，图标加字（矮屏只留字） | 图标加字，黄贴纸只包住图标 | 整格黄等于在屏幕底部再加一条外框；只包图标，颜色少一半，选中照样一眼看得出 |
| ⚑ 首页的页名 | 首页顶栏只有工作区胶囊（“只显示一个 Server Name”），其他一级页把页名写在导航行里 | 默认每个一级页都写大标题，首页写 Home；和线上一样的版本保留在 NavBar 里 | 胶囊表示在哪个工作区，标题表示在哪一页；四个 Tab 的标题在同一个高度 |
| 头的高度、Rail 的宽 | Brutal 主题：头 62，Rail 64（含 2px 边） | 头 56，只放图标的 Rail 56（另加 1px 分区线），左上角 56×56 | 评审觉得 Rail 偏宽；左上角必须是正方形（产品测试 leftrail-square-slot 钉住的规则），所以头跟着一起变。56 和 56 正是产品 Elegant 主题的值 |
| 正在干活 | 手机 Tab 栏上面、桌面侧栏底部一条实时条（LiveAgentActivityBar） | 写在原处：标题下的一行摘要、agent 行的第二行、频道顶栏的副标题、Working now 列表 | 见下面“正在干活写在原处” |
| 切换工作区（手机） | 跟着胶囊弹出的框（PopoverPopup） | 从底部升起的列表，内容和产品的切换菜单一样 | 评审：用 sheet 选，不跟着按钮弹框；拇指够得着，工作区多了也放得下 |
| 表情回应的图 | 7 个自己画的快捷回应（`packages/web/assets/reactions`），里面有鼠尾草绿、浅钢蓝和奶油色的弧形高光 | 同样 7 个，造型照旧，颜色换成这里的色板（绿、青、粉），高光改成白色方像素；暗色加一圈模切边 | 和贴纸、像素头像是一套语言；每个颜色都在色板里，两种主题都看得清 |
| 区域之间的线、阴影 | 2px 纯黑线；控件、卡片、菜单、对话框带 2–6px 硬影 | 1px `line-seam`；只有品牌插画带硬影 | 纯黑线太抢、把画面切碎（第五轮评审）；墨线留给“这是控件”，影子到处都有就什么都没说 |
| 提示：toast、tooltip | 亮色主题黄底黑框 | 中性的 `hud` 深色 | 黄表示“你”；提示只是顺带一句（第五轮评审）；产品 Elegant 主题本来就是这样 |
| 导航选中（侧栏行、设置导航） | 粉底加硬阴影 | 黄贴纸 | 选中是“你在这”；raft-ui 的配色规则也把它归给黄 |
| 暗色 Rail 的选中 | 亮成内容的颜色（Elegant Dark 不用黄） | 黄贴纸 | 和侧栏选中行、Tab 栏一样：选中是“你在这”；外框本身仍是中性的 |
| 分页标签的选中 | 下划线 | 默认黄贴纸；下划线的版本也画了（待定） | 和侧栏行、分段控件是同一种“你在这” |
| 未读 | 粉底白字（2.4:1）；线程新回复是青 | 一律粉底墨字 | 彩色块上一律墨字；一个意思一个颜色 |
| 焦点环 | raft-ui 的文字说用黄 | 墨 | 和产品的 index.css 一样 |
| 单选的选中 | 黄底 | 墨色圆点 | 和复选框一样：选中的值是墨 |
| 状态签、运行时签 | 饱和色实底加墨框 | 浅底，加一个像素或图标 | 一屏会有十几个，饱和色只留一个像素那么大 |
| 第三级文字 | 亮 60% 墨，暗 `#989895` | 62% 墨，`#9e9e9b` | 放在任何浅底、浮层上都过 4.5:1，不用记例外 |
| 出错的字 | `#F70720` / `#f97264`（白上 4.2 / 2.8:1） | `#b5321a`（6.1:1） | 文字要过 4.5:1；删除按钮仍是 `#f97264` |
| 离线灯 | Tailwind 的 gray-400 | 色板里的 `stone` | raft-ui 不用 Tailwind 的默认色板 |
| 点和转圈 | 圆点、圆环 | 方像素 | 规则 6：所有的点都是像素 |
| 抽屉、底部弹层 | 2px 墨框加硬影 | 分区线边加软阴影；模态的抽屉下面铺遮罩 | 浮层一律用 `shadow-float` |
| 暗色模式的控件 | Elegant 主题：淡色洗底的按钮和签、圆头像 | 贴纸照旧 | 粉按钮、方头像、墨字在两种主题里是同一个东西 |
| 没有照片的人 | 人形图标 | 首字母 | 首字母认得出是谁，人形图标只说“这是个人” |
| 开关 | 亮色主题是方的 | 胶囊；颜色一样，打开是黄 | 方的开关认不出来 |
| 上传进度 | 粉 | 青，一条独立的细轨道 | 进度是被动的指示，粉留给“去做” |

## 2026-10-18 这一轮定下的
网页端照这套系统重画时，评审一条条提出、已经在 raft-ui 和网页端实现的取舍。

| 哪里 | 以前（这里或产品） | 现在 | 为什么 |
| --- | --- | --- | --- |
| 抽屉 | 不铺遮罩 | 模态的抽屉滑入，页面其余部分铺和对话框一样的遮罩 | 抽屉开着时后面点不了，遮罩把这件事说出来；动画只留给抽屉，它从哪来一眼看得出 |
| 居中弹窗 | 对话框淡入缩放 150ms；搜索弹窗不暗、带浮层的打开动画 | 对话框、确认、搜索、任务详情、大表单：一律铺遮罩，没有动画 | 一种规则；居中的弹窗本来就在那儿，不需要从哪里来。以后要加动画，作为一次有意的变更再定 |
| 一次填完的大表单 | 右侧宽抽屉 640 | 居中宽弹窗 896：分段列表 + 分段 + 底栏提交 | 字段多，要的是一张完整的表，不是贴边的一条；分段列表让长表单可以跳着填 |

| 面板头的图标按钮 | 44，字形 22 | 桌面 32，字形 18，点击区仍 44；手机仍 44 | 44 的按钮挨着 17px 的标题显得笨重；手机上是拇指，留 44 |
| 网页版桌面 | 外框只有 Rail，不加顶栏 | 一条 48 高的外框顶栏，正中是搜索 | 网页版用顶栏搜索；它是外框，不是内容，黄照样只铺在外框上 |
| 分段控件的轨道 | 没写宽度，常被撑满 | 轨道贴着分段；只有作为表单里唯一的选择时才撑满、各段平分 | 撑满的灰轨道右边是一截没用的灰 |
| 按钮尺寸 | 三档，只写了“列表行和卡片用小号” | 由用途定：底栏、表单、面板底部整宽操作 44；行、卡片、横幅、工具栏、面板头 32；登录页那个整宽粉按钮 52 | 同一种用途在任何地方都是同一种大小 |
| 手机顶栏两头的按钮 | 右边的图标框在 16；返回用 chevron，往左挪 7px，让尖落在 16 | 两头互为镜像：都离屏幕边 3px，图标框离边 14；返回用 arrow-left（和产品一样） | 评审：返回贴边贴得太紧，和右边不对称。按图标的墨对齐时，每个图标自带的空白不一样（箭头、齿轮、⋮ 能差到 9px），按钮跟着图标乱跳；镜像以后两头的图标中心对称，常见图标的墨正好落在 16 附近。chevron 的墨只占框的中间，要单独挪；arrow 和别的图标一样铺满框 |

| 能改的头像 | 两种遮罩；只在悬停时出现 | 一种：遮罩加动作图标，悬停、键盘焦点、上传中都显示 | 只靠悬停，键盘用户不知道它能改 |

## 几个关键决定

**结构跟产品，样子是这里的。**产品代码里已经有大量写明的决定：Tab 栏只在一级页、工作区只在首页、手机和桌面用同一个菜单、空状态只有一种样子、任务在对话里是一枚标记。这些是用出来的结论，设计系统照搬；它负责的是颜色、线、形状，以及品牌元素用在哪里。

**通用的和 Raft Chat 自己的分开写。**Raft 会有很多产品（Tasks、Calendar、Artifacts、Sites、Meeting、Canvas…），它们共用颜色、组件和页面骨架，但各有各的入口和首页。所以“访客没有 Members”“首页头三行是 Search、Activity、Saved”这类规则写在《Raft Chat》，不写进导航的通用规则；新产品照《模式》搭骨架，再写一页自己的信息结构。

**黄只铺在外框上。**颜色放在哪里，代价不一样：放在要读的地方（消息、卡片、按钮），每看一眼都要多分一点神，一天下来会累；放在不用读的地方（顶栏、Rail），几乎不占注意力，又每屏都在，Raft 一眼就认得出。所以官网那条黄只铺在外框上，内容回到白纸。

**分区线取 45% 的墨。**15% 的发丝线在白上和黄上都只有 1.4:1，叠在黄上几乎看不见；2px 纯黑是全屏最黑的线，会把画面切成一格一格。在中间试了几档：30% 在黄上还虚，40% 离 3:1 差一点，50% 开始像控件的墨线。45% 在白上刚过 3:1，叠在黄上是一道暗金，和黄融在一起。

**彩色块都是贴纸。**糖果色和白纸只有 1.4–2.8:1，没有墨边就糊成一片。所以每块品牌色都带 1.5px 墨边、上面一律墨字，暗色也不反色；浅底只是高亮，不算贴纸。

**控件没有阴影。**“按这里”已经有三样东西表示：粉色、墨线、每屏最多一个。第四个信号是多余的：暗色里黑影本来就看不见，按下时位移还会让旁边的东西跟着抖。硬阴影只留在品牌插画里，反而更像贴纸。

**黄 = 你，粉 = 去做。**raft-ui 的配色规则把黄给“提示和交互的表达”，把粉给“核心动作”，并且不许拿黄做按钮。这里再收紧一步：黄只说“你”（你在哪、你选的、叫到你、你找的、你的工作区），所以没有黄色按钮，提示也不用黄。

**未读用粉，不用黄。**产品的提醒点组件默认就是粉，代码注释说“brutal-pink is the canonical unread color”。黄在产品里还是“忙”的状态灯；未读要是也黄，一个黄点就分不清是“有事等你”还是“有人在干活”。

**选中分三种。**导航里的选中是黄（你在这）；内容里挑出来的一项是青（这一项，和产品的列表选中一样）；勾上的复选框、选中的单选是墨（一个值）。全用黄的话，列表里一打开就是一大片黄。

**暗色外框是中性的。**暗色模式就是为了把亮度降下来；整条黄外框在暗色里会是全屏最亮的东西，产品的暗色主题也完全不用黄。外框里只有 Rail 的选中项是黄贴纸：它表示“你在这”，不属于外框。

**方头像，身份交给像素脸。**人和 agent 都是方的，脸已经说明了是谁，形状再说一遍是多余的。agent 的底色是像素形象自带的；频道是地方不是“谁”，没有身份色。

**灯不闪，没有“正在输入”。**产品专门去掉了呼吸灯：一直循环的动画会让页面按屏幕刷新率不停出帧（开着弹窗时 144fps、GPU 80%，停掉以后 2fps、3%）。一屏十几个头像一起闪也确实干扰阅读。正在干活就是一盏静止的黄灯，加一句在做什么。

**正在干活写在原处。**从头想：人看实时情况，是想知道有没有谁在干活、是谁、在干什么。产品的实时条把这三件事都塞进一条贴在 Tab 栏上面的横条：它占着拇指最常碰的位置，内容一直在变，却和你正在看的那一页无关，评审也觉得难看。这里把它拆开放回原处：页面顶上一行摘要（几张脸、几个人），agent 那一行写它正在做的事，频道顶栏写谁在这里干活，想看全部再点开 Working now。

**Rail 收窄，左上角还是正方形。**产品负责人在代码里钉过一条：桌面左上角放工作区的那一格必须是正方形，不管别的组件怎么改（有专门的 UI 测试）。Rail 从 64 收到 56，头也跟着从 62 收到 56，所有的头一起变，分区线照样对齐。图标加字的版本要放下 Computers 这样的名字，只能 68 宽，它的左上角是 68×56，和那条测试冲突：这个版本要是选上，就得一起改那条测试，或者让它的头也变成 68 高（所有的头跟着变）。这一点要你来定。

**进度不贴边。**进度条或彩色条带贴在圆角卡片的某一条边上，靠近圆角的地方会被切成奇怪的形状。所以进度一律是容器里面的一条独立细轨道（4px，2px 圆角）：文件卡里在文件名下面、和文字左对齐，composer 的缩略图里离四边 6px；两处是同一条轨道。

**不用全大写。**全大写让单词失去轮廓，读得更慢；中文没有大小写，中英混排时只有英文显得特别突出。产品把它留给分组标题和对话框标题，这里连这两处也不用，层级只靠字号、字重和颜色；能点的字和产品一样用 Title Case。全大写只留给引导页的步骤签。

**字体用官网的。**Space Grotesk 和 Space Mono 是最便宜、覆盖面最广的品牌载体；中文回落到苹方和思源黑体。
