# Raft Design System

The Raft Design System is the design language of every Raft product: Raft Chat today, and Tasks, Calendar, Artifacts, Sites, Meeting and Canvas next. Raft is a shared workspace where people and agents chat, hand off work, write, meet and ship in the same place, and people keep it open all day. These docs are for everyone who builds Raft, people and agents alike. They explain why Raft is designed the way it is and how to design something new, so that every product keeps one consistent character. The system is two things: the guidelines on this site, and [raft-ui](./about/use-raft-ui.md), the React components that implement them.
