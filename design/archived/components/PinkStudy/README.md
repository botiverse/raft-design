# PinkStudy

粉色按钮的色号和字色研究。结论：用黑字，所以粉色往淡里调——`pink` = `#FF99C3`。

## 结论

- **字色用黑**（`sticker-ink`）。所有“看起来是粉”的粉上，白字只有 1.8–3.1:1；按钮文字 14–16px，需要 ≥4.5:1。白字要达标，粉得暗到 L≈58%（`#D71F75`），那已经是树莓红：跳出了糖果色家族，还会和 `red`、`danger` 撞色。
- **既然用黑字，粉就往淡里走。**黑字的对比度只取决于粉有多亮：越淡越清楚。官网的 `#FE7DA8` 在八个品牌色里偏深（相对亮度 0.39，只比珊瑚红亮）；`lavender` `orange` `cyan` 都在 0.47–0.50 这一档。
- **色号用 `#FF99C3`**（oklch 80% .131 354）：提到糖果色主带（0.48），饱和度仍在 sRGB 顶上，一眼还是粉；色相比官网微微偏冷，免得变淡后发橙。黑字 9.5:1（AAA）。
- **淡到这里就停**：再淡（比如 `#FFA6C1`）就成了 pastel，会和 `pink-soft`（人类头像的浅粉底）分不开，不再像“去做”。
- 上一版的 `#FF78B8` 更鲜，但其实更深了一点（7.7:1），方向错了，已弃用。变种的 `#FF5388` 更深：白字 3.1:1，黑字 6.1:1。

## 规则

- 改 `pink` 时同步检查 `pink-soft`，以及这张研究页里的对比度。
- 所有品牌色填充上都只用 `sticker-ink`，不要为某一个颜色破例用白字。
