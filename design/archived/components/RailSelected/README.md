# RailSelected

黄色 Rail 上的选中态对比：A 墨块、B 白贴纸、C 白底无框，亮暗各一版，旁边带着侧栏一起看。结论是 **B 白贴纸**。

## 三种方案

- **A · 墨块**：最醒目（墨对黄 13:1），但它是整屏最黑、最重的一块，会抢内容的注意力；旁边侧栏的选中又是黄色贴纸，一黑一黄两套语言并排。
- **B · 白贴纸（采用）**：白底 + 1.5px 墨线 + 墨图标。和侧栏、分段控件里的黄色选中是同一种“色块 + 墨线”，只是换了颜色；也和官网黄色顶栏上那颗白色 EN 按钮一个语言。白对黄只有 1.4:1，墨线把边界对比拉到 13:1。
- **C · 白底无框**：最柔和，但白对黄只有 1.4:1，选中态几乎只靠字重；墨线一拿掉，也不像 Raft 了。

暗色模式下 A 和 B 一样：黑色 Rail 上的黄贴纸。

## 规则

- 选中 = 一张贴纸：纸面上用黄贴纸，黄色 Rail 里用白贴纸。由 `frame-active`、`on-frame-active`、`frame-active-edge` 控制。
- Rail 顶上的 mark 直接放在黄色上，不加白底块，免得和白色选中态混淆。
