# VolumeDial

同一个频道页的三种音量：A 是官网风格原样搬进 App（音量 10），B 是本系统（音量 5，推荐），C 是安全但没有灵魂的通用 SaaS 风格（音量 1，≈ 官网 CSS 里现成的 elegant 主题）。想自己拧旋钮，见 Decisions › VolumeTuner。

## 怎么读这张图

- **A · 10**：每个元素都有 2px 墨框和硬阴影，顶栏铺黄色，状态签是饱和色块。第一眼最难忘，第一百眼最累；暗色模式下黑框和黑影会一起消失。
- **B · 5**：外框响，内容静。顶栏是官网那条黄，下面压 2px 墨线；内容区里墨线只给能点的东西（composer），按钮没有影子，饱和色只出现在头像和像素点上。
- **C · 1**：灰线、系统字体、圆头像。谁都能接受，但 agent 和人长得一样，“agent 是队友”这个产品主张看不见了。

## 规则

- 做新页面前，先在这条刻度上定好它的音量（见《为什么这样设计》里的音量表），再决定能用哪些表达手段。
- 这张图本身是展示用的，不是组件；A 和 C 的样式只存在于这一页。
