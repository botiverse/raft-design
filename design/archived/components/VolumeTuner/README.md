# VolumeTuner

音量调节器：受变种里“Brutality Dial”的启发，用真实组件做的交互页。调外框（官网黄 / 纸色）、圆角、控件描边、硬阴影、粉色和字色、亮暗主题，右边的频道页实时变化，下面输出可以直接发给前端的 CSS 变量。

## 怎么用

- 三个预设：**推荐**（音量 5，就是这套系统现在的值）、**官网原味**（音量 10）、**太素**（音量 1，变种玫红 + 白字）。
- 音量是一个粗略打分：外框黄 +2，圆角 ≤4 +2 / ≤8 +1，描边 1.5px +1 / 2px +2，硬阴影每档 +1，底分 1（像素和字体一直都在）。
- 粉色一栏会实时显示字色对比度和等级（AAA / AA / 仅大字 / 不过线）。
- “复制”在预览框里不能直接写剪贴板时，会自动选中代码，按 ⌘C 即可。

## 规则

- 调节器是讨论工具，不是规范本身。定下来的值写回 tokens.json，这一页的“推荐”预设跟着改。
- 日常工作页的推荐区间是 4–6；8 以上留给引导页和营销页。
