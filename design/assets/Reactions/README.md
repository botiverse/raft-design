# Reactions

Raft's 7 quick reactions, in this order: `thumbs_up.svg`, `heart.svg`, `party_popper.svg`, `eyes.svg`, `fire.svg`, `joy.svg` and `check_mark.svg`. They come from the product's own set (`packages/web/assets/reactions` in the Raft web app), with the same subjects, order and shapes, and three changes for this system ([Brand](../../foundations/brand.md#reactions)):

- Every color comes from the palette. The thumb's cuff is cyan (light steel blue in the product), the check mark is lime (sage green in the product), and the confetti adds pink and cyan. Yellow, orange, red and lavender are as in the product.
- Highlights are white square pixels instead of cream curves: every dot is a pixel.
- They are drawn on a 24px grid with a 2px ink line. In dark mode they get the die-cut edge, like stickers and pixel avatars.

The rules for their sizes, dark mode and accessibility are in [Brand](../../foundations/brand.md#reactions).
