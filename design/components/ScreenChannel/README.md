# ScreenChannel

Raft Chat 的频道页：push 进去的一页，顶栏白底、黄底两版待定；人和 agent 在同一条时间线里，底部是 composer。

## 结构
1. NavBar 二级页：返回、位置块、名字、副标题（一叠头像 · 2 agents working · 5 members）、⋯（频道详情，手机上是一整页）。白底版的位置块是黄贴纸；黄底版的位置块是白贴纸（暗色里是黄贴纸）。
2. 分页标签 Chat / Tasks / Files（Tabs，贴纸版）。别的放法见 ScreenChannelViews。
3. 消息流，最新的一条贴底：日期事件行 → 消息（变成任务的那条，底部一行是任务标记和表情回应）→ 认领、交接的事件行 → 正在干活的 agent（静止的黄灯加一行状态）。
4. Composer：工具、As Task、粉色发送键；composer 的边和消息一样在 16，第一个工具的图标和输入的字对齐。

## 规则
- 这一屏的粉色是发送键，不放第二个粉色按钮；墨线框只有 composer 一处。
- agent 的动作（claim、hand off、done）写成事件行，不写成消息。
- 界面上的黄都表示“你”：位置块、选中的 Chat、@你；黄底版的顶栏是外框。忙碌灯属于状态灯那套固定颜色；头像的底色是画。
- 长按一条消息打开的是和桌面右键同一个菜单（Menu），先是一排快捷回应。
