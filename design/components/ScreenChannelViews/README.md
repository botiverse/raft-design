# ScreenChannelViews

Raft Chat 的频道里，对话、任务、文件三种内容怎么切换：四个版本，等挑选。前三个是一次看一种，D 让任务和对话同时在屏幕上。最后两台手机是 D 在手机上的样子。

## 四个版本
| 版本 | 结构 | 好处 | 代价 |
| --- | --- | --- | --- |
| A 贴纸分页（默认） | 面板头下面一行 Tabs，选中是黄贴纸；三种内容轮流占满主区 | 和侧栏、分段控件是同一种“你在这”；一眼看得出在哪个视图 | 多一行；任务和对话不能同时看 |
| B 下划线分页 | 同一行 Tabs（`rf-tabs--line`），只写字，选中是墨色字加 2px 墨线 | 和产品现在一样；颜色更少 | 选中没有 A 那么明显 |
| C 顶栏里的分段 | SegmentedControl 坐在面板头右边，⋯ 前面 | 省掉一行，主区多出 44 高 | 面板头挤；频道名长、或者手机上放不下时退回 A |
| D 任务在右边一栏 | 对话一直在主区；面板头右边的 Tasks（带数量）、Files 是开关（`rf-tabs__item` 加 `aria-pressed`），打开的那个是黄贴纸，停在右边（Panel 的 `rf-aside`，380） | 一边聊一边看任务、拖状态；对话不被换走 | 主区变窄；一次只能开一栏 |

## D 在窄屏和手机上
- 右边一栏一次只停一个：任务、文件、线程、资料互相替换，打开新的就关掉旧的。
- 桌面主区不够 680 时，右边一栏盖住对话，× 关掉回到对话。
- 手机上没有右边一栏：频道顶栏右边是任务和文件两个图标按钮，点任务 push 进这个频道的任务页（标题 Tasks，副标题写频道名和几个没做完，右上角 + 新建），返回回到对话。

## 规则
- 一个版本里只用一种，所有频道都一样；不要在同一个产品里混着用。
- 计数（Tasks 5）用 Space Mono 写在字后面，几个版本写法一样。
- 线程不放进这几个视图：线程总是在右边一栏（手机上 push 一页），见《Raft Chat》。
