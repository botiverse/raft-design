# ScreenDesktop

Raft Chat 的桌面频道页：黄色 Rail → 奶油色侧栏 → 白色主区。界面用中文，演示苹方回落和中英混排。

## 结构（从左到右）
1. Rail（只放图标，56）：工作区；搜索、聊天、动态、任务、成员、计算机；底部通知、帮助、设置。动态上挂一个粉色提醒点。另一个版本是图标加字，见 Rail。
2. Sidebar：头上写“聊天”，右边是正在干活的那叠头像和人数；频道、Agents、私信。在干活的 agent，右边写它正在做的事（写发布说明、改 #31 的圆角），其他的写运行时。
3. 主区：面板头（位置块、名字、一行说明）→ 分页标签 对话 / 任务 / 文件 → 消息流（证据条、带任务标记的消息、交接事件、正在干活的 agent）→ composer（@ 委派 chip、作为任务、粉色的“发送 ↵”）。

## 规则
- 网页版的外框是 Rail 加一条 48 高的顶栏（`rf-topbar`）：左边工作区、正中搜索框、右边“谁在干活”和铃铛，都是 36 高的外框项，离顶栏上下 6、左右 8；工作区按钮和下面 Rail 的按钮对齐。这时 Rail 没有头，第一个入口离顶栏的分区线 8。桌面 App 的标题栏是同一条。
- Rail、侧栏、主区之间，侧栏头和面板头下面，都是同一种分区线，两个区域之间只有一条；侧栏头、面板头都是 56 高，线对齐。
- 暗色的外框和产品一样是中性深色，不用黄：Rail 和侧栏 `#0d0d0b`，主区 `#1b1b19`；Rail 的选中项是黄贴纸，和侧栏的选中行一样。
- 侧栏底下不放实时条。打开线程、任务时怎么放，见 Panel 和 ScreenChannelViews；任务页没有侧栏，看板直接接在 Rail 右边。
