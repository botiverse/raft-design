# ScreenOnboarding

引导页：第一次打开 App 时，可以把官网整个搬进来——整屏黄色、倾斜漂浮的像素贴纸、半调网点、大标题。这是《模式》里“品牌元素用多少”的最后一行：用得最多的地方。

## 结构
1. 顶部：`rf-logo` 和 Skip（ghost）。
2. 贴纸组：2 个 `--xl` 加 3 个 `--lg` 的头像贴纸，各自倾斜、漂浮，背后一块半调网点。亮色整屏是黄的，所以挑底色不是黄的形象。
3. 文案：步进点、步骤签“Step 1 of 3”（Space Mono 12 全大写，整个 App 里唯一的全大写）、40/44 的大标题、一段正文。
4. 底部：整宽的 `rf-btn--primary rf-btn--lg`，加一个 ghost 的次按钮。

## 规则
- 亮色整屏 `yellow`，字一律 `sticker-ink`；暗色回到 `paper`，贴纸保持原色。
- 整屏黄、半调网点、40px 标题、全大写的步骤签只出现在这里和登录、营销页；agent 主页只用大贴纸；工作页（包括空状态）都不用。
