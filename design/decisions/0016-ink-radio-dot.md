# 0016. A selected radio is an ink dot

## Context

In the product code a selected radio is filled yellow.

## Decision

A selected radio is an ink dot, as a checked checkbox is ink: a chosen value is ink.

## Consequences

Radios and checkboxes agree, and yellow stays for "you are here".
