# 0020. The offline light is stone from the palette

## Context

The product code colors the offline light with Tailwind's `gray-400`. raft-ui doesn't use Tailwind's default palette.

## Decision

`presence-offline` is stone, from the palette.

## Consequences

Every presence light comes from the palette.
