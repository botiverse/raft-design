# 决策

决策记录写下一个跨越整个系统的重大选择：它改变一条原则、一种材质或一种颜色的含义，适用于多个产品，或者推翻产品现有的做法。每条记录写明当时的情况、决定了什么、由此带来什么，以及和什么做过权衡，这样以后重新审视这个选择时，不用去猜当初为什么这么定。

较小的规则不写记录。它们的理由就写在规则旁边，放在负责它的那一页：基础、模式、组件文档、内容章节、人和 agent，或者原则。

- 编号永不复用，也不重新编号。编号中的空缺，是一条规则连同理由已经移到负责它的页面的记录；它的旧地址会重定向到那里。
- 被后来的选择推翻的记录标为 `superseded`，并链接到取代它的记录。
- 还没做出的选择放进[待定问题](./open-questions.md)，并写明做出决定之前使用的默认做法。

怎么写一条记录，见[编写指南](../authoring/README.md)和[决策模板](../authoring/templates/decision.md)。
