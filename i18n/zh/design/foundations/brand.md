# 品牌

Raft 从官网的粗野风格里保留了几样东西：黄色、墨色线条、方形像素、Space Grotesk 和 Space Mono。官网要让人一眼记住；产品则是每天要用好几个小时的。所以日常使用的产品只在几个固定位置放品牌色，页面越接近第一印象，就越可以多用官网的元素。

## 原则 {#principles}

- **日常使用的产品用最少的品牌元素。** 列表、对话、任务、设置和空状态只有外框和小块颜色，别的都没有。
- **品牌插画不进日常页面。** 带硬阴影的大贴纸只出现在个人资料页和设置流程的最后一步；网点、倾斜的预览或拼贴和 logo 只出现在登录页、注册页、创建账户或服务器的页面，以及新手引导 v3 里进入 App 之前的每个页面。
- **最近动态卡片可以放一个小尺寸 Ottie 插画。** 这是已批准的角色设计，只适用于这张卡片，不代表可以在其他日常页面增加品牌插画。四种姿势和动效与 [OtterIndicator](../../packages/ui/src/components/steps/steps.md#ottie-illustration) 保持一致。
- **外框上放的是你的服务器，不是 logo。** 日常页面的外框显示你的服务器（手机主页上的工作空间按钮，网页顶栏里的工作空间按钮和横条），从不显示 Raft 标志。

## 品牌用多少 {#how-much-brand}

每一行在上一行的基础上增加。

| 页面 | 可以用 |
| --- | --- |
| 日常页面：列表、对话、任务、设置、空状态 | 黄色外框、工作空间按钮、最多一个粉色主操作、墨色描边的控件、小块颜色（如头像和在线状态灯） |
| 单个 Agent 或人的个人资料页，以及服务器设置流程的最后一步 | 另加：99px 的像素贴纸，带硬贴纸阴影（`shadow-sticker`）。在个人资料页上它保持静止；在设置的最后一步它跳一下（[动效](./motion.md#usage)） |
| 登录 | 另加：logo，放在白色页面上方 56px 高的外框条里；表单标题上方放 Raft 标志 |
| 注册、创建账户或服务器，以及新手引导 v3 里进入 App 之前的每个页面 | 另加：从 1024px 起，表单右边放一块品牌面板，底色为外框色，上面是网点（14px 网格上的 1.5px `line-seam` 圆点），网点前是这个页面要创建的东西的预览，倾斜 −1°，带硬贴纸阴影；页面还没有创建出看得见的东西时，改放一幅由 Agent 的像素脸和小组件拼成的拼贴（[引导](../products/raft-chat/onboarding.md#split-pages)）。logo 放在表单左上角。1024px 以下，在普通表单上方放与登录页相同的外框条 |

表格越往下，越接近官网。后三行的东西都不出现在日常页面上，包括日常页面的空状态。在已上线的流程里，新服务器的设置流程以对话框的形式叠在服务器页面上，除最后一步外都算日常页面；在新手引导 v3 里，设置的各个步骤是带品牌面板的分栏页面，App 在这些步骤之后才打开（[引导](../products/raft-chat/onboarding.md)）。

- 登录页的标题用 `text-title`；创建服务器页面的标题用 `text-title`，640px 起用 `text-display`。`text-hero` 只用于一种页面上的服务名称：人用 Raft 登录另一个服务的页面（Login with Raft）。
- 不要让整屏铺满黄色，也不要加漂浮的贴纸：产品的品牌页面改用上面说的外框面板。
- 设置流程的步骤标签用句首大写（"Set up your server"）。[0002](../decisions/0002-no-all-caps.md) 仍然允许引导屏上有一个全大写的步骤标签；产品没有用。

## Logo {#logo}

| 文件 | 用在 |
| --- | --- |
| `raft-logo.svg` | 浅色背景 |
| `raft-logo-yellow.svg` | 深色背景（官网页脚的配色） |
| `raft-mark.svg`、`raft-mark-yellow.svg` | 同样两种背景，只有标志 |

文件在 [`design/assets/Logos`](../assets/Logos/)。raft-ui 把标志导出为 `RaftLogo`，文字标导出为 `RaftWordmark`，两者组合导出为 `RaftLogoLockup`。

- 浅色背景上用墨色描边，深色背景上用白色描边。logo 是双色图稿：换文件，不要改它的 CSS `color`。raft-ui 的导出项在深色模式下会自己换成白色描边。黄色描边是官网页脚的版本，不用在产品里。
- 标志直接放在黄色背景上，后面不垫底块。
- logo 只在品牌页面（登录、注册、创建账户或服务器的页面，以及加载屏）和应用之外的公开页面上显示，比如公开的 Artifact 或公开的服务器页面。公开页面没有服务器外框，所以由标志开启它的页头，并为访客链接到 Raft 官网。
- 不要把标志放在日常页面的外框上。

## 回应 {#reactions}

Raft 自己画了 8 个回应：7 个快捷回应（thumbs_up、heart、party_popper、eyes、fire、joy 和 check_mark）和 beers（huxijin，2026-11-23）。文件在 [`design/assets/Reactions`](../assets/Reactions/)。

- 在 24px 网格上用 2px 线条绘制。所有填充色都取自色板（黄、青、橙、红、薰衣草紫、青柠绿、粉），高光画成白色方形像素。产品原来的那套用了鼠尾草绿、浅钢蓝和奶油色的弧形高光，这些都不在色板里；重新配色后，回应与贴纸和像素头像是同一种语言，每种颜色在两种模式下都清晰可辨。
- 每个图的描边用它主色更深一号的颜色，不用墨色。图里面的细节，比如眼睛和嘴，仍然用墨色。描边要和回应所在的四种底色都有 3:1 的对比度（[无障碍](./accessibility.md)）：白底、浅色悬停灰 `#EBEBEB`、深色画布 `#251C15` 和深色卡片 `#362C24`，这样一套图两种模式通用。画新的回应也在这四种底色上量。现在用的描边色，在四种底色上都在 3.36:1 以上：

  | 描边 | 用在 |
  | --- | --- |
  | `#AD7300` | thumbs_up、joy、beers |
  | `#DD4E3A` | heart |
  | `#8271D1` | party_popper |
  | `#1489AC` | eyes |
  | `#CB6026` | fire |
  | `#428E58` | check_mark |

- 不要给回应加模切边。回应是消息里的内容，不是贴纸；在 16px 下多一圈边会显得又粗又挤。墨色描边在深色模式下不过关（在深色画布上只有 1.1:1），而为深色模式再准备一套图，网页和 App 就要多维护一套（huxijin，2026-11-23，#proj-raft-ui:6ed5ba75）。
- 尺寸：在回应里 16px，在菜单的快捷回应中 22px，单独出现时 18px。
- 其他所有回应用系统 emoji。只有产品需要时才画新的，并遵守这些规则。
- 对辅助技术隐藏图画，给承载它的按钮加 `aria-label`。
